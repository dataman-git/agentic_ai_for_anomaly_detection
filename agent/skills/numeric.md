## Skill: Analyze Numeric Columns

Use this when the user wants to:
- analyze numeric data
- understand distributions or summary statistics
- detect outliers
- examine relationships between variables

Actions:
1. Call `analyze_numeric_columns`
2. Optionally call `detect_outliers`
3. Optionally call `correlation_matrix`

Output:
- summary statistics (mean, std, min, max)
- detected outliers
- correlations between variables
